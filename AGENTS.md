# gambling-with-claude-code

Мод для Claude Code CLI: казино прямо в терминале. Фишки — токены, которые Claude Code сжёг за сегодня. Реальных денег нет и не будет.

Полноценное казино под все агенты (браузер, окно поверх экрана) живёт в отдельном репо `token-gamble`. Здесь — только мод для Claude Code.

## Правила

- Язык общения и документов — русский.
- Никаких реальных денег, покупок, вывода. Ирония про вред гемблинга — часть игры.
- Ощущение важнее фич: каждая победа должна чувствоваться. В терминале это ASCII-арт, вспышки цвета, тряска, частицы из символов, звук (`$.audio.play`).

## Как устроено

- `hooks/register.tsx` — мод: команда `/gamble`, панель, анимация.
- `hooks/slot.ts` — логика слота без движка, её тесты в `hooks/slot.test.ts`.
- `tools/count_today.py` — сколько токенов Claude Code сжёг с полуночи (читает `~/.claude/projects/**/*.jsonl`).

## Проверка

- `claude plugin validate .` и `claude plugin test .` — до коммита.
- Запуск: `claude --plugin-dir ~/dev/gambling-with-claude-code`, потом `/gamble`.
- Моды не работают в `claude -p`, SDK, VS Code-чате и WSL-сессии десктопа. Смотреть глазами в обычном терминале.
